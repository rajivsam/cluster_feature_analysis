Workspace Specification: cluster-geometry-profiler


1. Project Overview & Core Philosophy

cluster-geometry-profiler is a lightweight, scikit-learn-compatible Python package for principled unsupervised cluster due diligence.

Core Problem Being Solved

In unsupervised clustering—especially on longitudinal or multivariate tabular data—there is no target variable y to weight features or correct distorted scales. When variables are correlated across features or across time lags (\(x_t, x_{t-1}, x_{t-2}\)), standard Euclidean distance double-counts shared variance (violating the information-theoretic Principle of Inclusion-Exclusion: H(X₁, X₂) = H(X₁) + H(X₂) - I(X₁; X₂)). This stretches feature space into artificial ellipsoids and produces exaggerated partitions driven by redundant variance rather than true underlying subgroups.

Two-Pillar Design Principle

Every recommendation generated by this package must triangulate the distance metric and clustering family from two independent dimensions:
1. Domain Similarity & Measurement Invariance (invariance): Enforcing what differences should equal zero distance before geometric inspection (Ratio/None, Translation/Interval, Scale/Cosine, Affine/Row Z-Score).
2. High-Dimensional Cluster Geometry (geometry): Probing whether data forms isotropic spheres, tilted linear ellipsoids, varying-density clouds, or curved non-linear manifolds—without relying on 2D embeddings (UMAP/t-SNE), which distort global distances.

3. Module-by-Module Implementation Requirements


3.1 src/cluster_profiler/invariance.py

Implement InvarianceTransformer(BaseEstimator, TransformerMixin) supporting:
• 'none': Identity transform (Ratio scale; absolute levels matter).
• 'translation': Row mean-centering \(x_i - \bar{x}_i\) (Interval scale; ignores baseline offset).
• 'scale': Row L2-normalization \(x_i / \Vert{}x_i\Vert{}_2\) (Cosine geometry; ignores magnitude).
• 'affine': Row z-scoring \((x_i - \bar{x}_i) / \sigma_i\) (Pure shape; ignores offset and amplitude).
• Edge-case rule: Always clip denominators (norm, std) at 1e-12 to prevent NaN/Inf on constant or zero rows.

3.2 src/cluster_profiler/diagnostics.py

Implement modular, pure diagnostic functions accepting NumPy arrays (n_samples, n_features):
1. compute_stability_metrics(X):
	• Returns n_to_d_ratio (N/D) and correlation matrix condition_number (\(\lambda_{\max} / \lambda_{\min}\), clipping eigenvalues at 1e-12).
2. compute_tail_metrics(X):
	• Returns max_abs_skewness and max_excess_kurtosis across columns.
3. compute_nonlinear_coupling(X, Z_whitened):
	• Gaussian MI Gap (Δ I): Computes empirical MI via sklearn.feature_selection.mutual_info_regression minus theoretical Gaussian MI \(I_{\text{Gauss}} = -\frac{1}{2}\ln(1 - \rho^2)\) across sampled feature pairs. Subsample to max 1500 rows for runtime efficiency.
	• Residual Volatility Coupling: Computes max off-diagonal absolute correlation of squared whitened components \(\text{Corr}(z_i^2, z_j^2)\) on components covering 95% variance.
4. compute_manifold_curvature(Z_whitened, n_neighbors=12):
	• Global Participation Ratio: \((\sum \lambda_i)^2 / \sum \lambda_i^2\).
	• Local Intrinsic Dimensionality: Levina-Bickel k-NN MLE estimator.
	• Geodesic-to-Euclidean P90 Ratio: 90th percentile of undirected k-NN graph shortest-path distances (scipy.sparse.csgraph.shortest_path) divided by ambient Euclidean distances (subsample to max 800 rows if N > 800).
5. compute_algorithm_disagreement(Z_whitened, k_test=4, random_state=42):
	• Computes adjusted_rand_score between KMeans (convex centroid assumption) and AgglomerativeClustering(linkage="average") (connectivity assumption).

3.3 src/cluster_profiler/profiler.py

Implement ClusterGeometryProfiler:
• Method .fit_audit(X, invariance="none"):
	• Validates input (raises clear ValueError on NaN or Inf).
	• Applies InvarianceTransformer.
	• Automatically applies QuantileTransformer(output_distribution="normal") internally if max_abs_skewness > 2.0 or max_excess_kurtosis > 7.0 before running covariance/MI probes.
	• Populates self.report_ dictionary with shape, invariance, metrics, and recommendation.
• Decision Logic (_synthesize_recommendation):
	• Rule 1 (Curved Manifolds / Non-Linear Loops): Triggered if geodesic_euclidean_p90_ratio > 1.8, (global_pr / local_id) > 2.2, max_gaussian_mi_gap_nats > 0.15, or max_whitened_sq_corr > 0.15.
		• Output: Geometry = "NON-LINEAR MANIFOLD", Transform = "Quantile + Spectral/Diffusion Embedding", Metric = "Geodesic / Diffusion Distance", Clustering = "SpectralClustering or HDBSCAN".
	• Rule 2 (Non-Convex / Varying Density): Triggered if convex_vs_connectivity_ari < 0.45 (without curved manifold flags).
		• Output: Geometry = "NON-CONVEX / UNEQUAL DENSITY", Transform = "Whitening", Metric = "Mutual Reachability Distance", Clustering = "HDBSCAN".
	• Rule 3 (Stretched / Correlated Ellipsoids): Triggered if condition_number > 5.0 (linear lag collinearity).
		• Output: Geometry = "STRETCHED ELLIPSOIDS", Transform = "PCA Whitening (or Ledoit-Wolf if N/D < 30)", Metric = "Mahalanobis Distance", Clustering = "GaussianMixture(covariance_type='full') or Whitened KMeans".
	• Rule 4 (Isotropic Spheres): Default when all above checks pass.
		• Output: Geometry = "ISOTROPIC SPHERES", Transform = "StandardScaler", Metric = "Standardized Euclidean", Clustering = "KMeans or Spherical GMM".
• Method .summary(): Prints a clean, human-readable ASCII/Markdown audit report.

3.4 src/cluster_profiler/pipeline_builder.py

Implement build_pipeline(profiler: ClusterGeometryProfiler, n_clusters: int = 4) -> sklearn.pipeline.Pipeline:
• Reads profiler.report_["recommendation"] and constructs an executable sklearn.pipeline.Pipeline chaining:
	1. InvarianceTransformer(invariance=...)
	2. QuantileTransformer(output_distribution="normal") (if flagged) or StandardScaler()
	3. PCA(whiten=True, n_components=0.95) or SpectralEmbedding (based on diagnosed geometry)
	4. Final estimator (KMeans, GaussianMixture(covariance_type="full"), HDBSCAN, or SpectralClustering).

4. Coding Standards & Constraints

• Dependencies: Keep core runtime dependencies minimal: numpy>=1.24, scipy>=1.10, scikit-learn>=1.3, pandas>=2.0. Do not add heavy deep-learning frameworks (torch, tensorflow).
• Scikit-Learn Compatibility: All custom transformers must inherit from BaseEstimator and TransformerMixin, implement fit(self, X, y=None) and transform(self, X), and pass sklearn.utils.estimator_checks.check_estimator where applicable.
• Determinism: Every stochastic operation (subsampling, QuantileTransformer, KMeans, mutual_info_regression) must explicitly accept and propagate random_state.
• Testing Mandate: Every geometric regime in tests/test_diagnostics.py must be verified against synthetic ground-truth generators:
	• Isotropic Gaussian blobs → predicts ISOTROPIC SPHERES.
	• Correlated AR(1) longitudinal lag matrix → predicts STRETCHED ELLIPSOIDS.
	• Concentric circles / Swiss roll → predicts NON-LINEAR MANIFOLD.
	• Translation-shifted identical sine waves with invariance="translation" → collapses distance to near zero.
